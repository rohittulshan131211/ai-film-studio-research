# Six-Month Research Plan

## Goal

Develop and evaluate a structured workflow for AI-assisted film production by independent creators.

## Workstreams

### 1. Workflow design

Define a standard data structure for scripts, characters, environments, props, scenes, prompts, references, generated outputs, and approval states.

### 2. Prototype iteration

Refine practical interfaces for project setup, asset tracking, production queues, human quality control, and export.

### 3. Evaluation

Run structured test projects and record:

- Input scripts and intended outputs
- Reference assets and prompt structure
- Generation failures and likely causes
- Human review decisions and revisions
- Consistency and completeness observations
- Creator feedback on usability and coordination effort

### 4. Documentation

Publish reusable prompt structures, checklists, data schemas, observations, and limitations so the research is useful to other creators.

## Milestones

| Period | Focus | Output |
|---|---|---|
| Months 1–2 | Workflow specification and prototype refinement | Versioned production schema and test checklist |
| Months 3–4 | Script-based test runs | Failure log and comparison notes |
| Month 5 | Creator feedback and iteration | Revised workflow and onboarding guide |
| Month 6 | Synthesis | Public research summary and next-step roadmap |

## Success criteria

The project will be considered useful if early testers can organise a multi-scene AI video project with clearer asset traceability and fewer avoidable coordination errors than an unstructured workflow.
