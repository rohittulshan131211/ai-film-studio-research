# Evaluation Protocol

## Purpose

This protocol describes how AI Film Studio Research will evaluate whether a structured AI-production workflow helps independent creators plan and organise multi-scene video projects.

## Evaluation unit

Each test run is one project created from a source script or creative brief. A run may include character, environment, prop, scene, prompt, generation, review, and export records.

## Procedure

1. Select a representative script and state the intended output.
2. Create a structured production plan and reference-asset list.
3. Generate scene outputs through the defined workflow.
4. Record every generation result as approved, rejected, or requiring revision.
5. Record the reason for each rejection or revision.
6. Compare the completed package with the original production plan.
7. Gather feedback from any participating creator about clarity, control, and coordination effort.

## Measures

The research will record the following observations without presenting them as universal benchmarks:

| Area | Observation |
|---|---|
| Traceability | Can each output be linked to its scene, prompt, references, and review decision? |
| Consistency | Are character, environment, and prop references maintained across scenes? |
| Completeness | Does the final package contain all required assets and metadata? |
| Error recovery | Can rejected items be identified and regenerated without disrupting approved work? |
| Creator effort | Does the workflow reduce avoidable coordination and hand-off work? |
| Usability | Do creators understand the process and maintain creative control? |

## Failure log

Every failed or rejected output should include, where possible:

- Project and scene identifier
- Prompt and references used
- Failure category
- Human review note
- Revision made
- Outcome after revision

## Limitations

Early findings will be exploratory. The project will not make claims about broad adoption, model accuracy, creator time savings, or general performance without sufficient evidence.
